Palworld-Takaro Bridge

Connect your Palworld dedicated server to Takaro for player management, server control, teleports, and in-game chat — no coding required.

Download the Bridge

What You Get

  • Server control from Takaro — kick, ban, announce, save, and shut down from the Takaro web console.
  • Player tracking — who's online, plus join/leave events.
  • Teleports — player-to-player and coordinate teleports.
  • Location lookup — live X/Y/Z coordinates for any player.
  • In-game chat — forward chat between your game, Takaro, and Discord.

Before You Start

You'll need three things:

  • A Palworld dedicated server you control (so you can edit its settings and restart it).
  • The Windows machine your server runs on (the bridge normally runs on the same machine).
  • A Takaro account — free to start. Get it at takaro.io or join their Discord for help.

Step 1 — Get Your Takaro Tokens

  1. Go to takaro.io and choose the Free tier to start.
  2. Check your email and finish creating your account, then log in.
  3. Click Game servers.
  4. Click Game Server Actions in the top right.
  5. Click Create a New Game Server.
  6. Choose Generic as the server type.
  7. Takaro shows a Registration Token. Copy it — you'll paste it into the config in Step 4.
  8. Click Cancel.

Step 2 — Enable the Palworld REST API

The bridge talks to your Palworld server through its built-in API. Turn it on in PalWorldSettings.ini, located at [Server folder]\Pal\Saved\Config\WindowsServer\PalWorldSettings.ini:

RESTAPIEnabled=True
RESTAPIPort=8212
AdminPassword=YourSecurePassword

Save the file and restart your Palworld server once so the setting takes effect.

Step 3 — Install & First Run

  1. Download PalworldBridge.exe and put it in your Palworld server folder — the folder that contains Pal (for example C:\gameservers\palworld).
  2. Right-click PalworldBridge.exe → Run as administrator. (Windows may warn "Windows protected your PC" → More info → Run anyway.)

Step 4 — Add Your Takaro Info

Open TakaroConfig.txt (now sitting next to the exe) in Notepad. The Palworld settings are already filled in for you — you only set two things:

SERVER_NAME=any name you want for your server
REGISTRATION_TOKEN=paste the token you copied in Step 1

Save the file (keep the name TakaroConfig.txt).

Step 5 — Start the Bridge

Run PalworldBridge.exe (right-click → Run as administrator). It connects to Takaro and your server shows up in your Takaro dashboard. Leave the window open while you want the bridge running; close it to stop.

Step 6 — Add the Takaro Modules

Modules add features to your Takaro server. Download these two (right-click → Save Link As, or open and use GitHub's Download raw file button):

  • Palworld - Commands — adds the player commands !sethome, !home, and !visit.
  • Discord Integration - Generic — connects your game to Discord: player join / leave / death messages, an online-offline status message, and two-way chat between the game and Discord.

(You can also browse them at the TakaroModules folder.)

Import each one into Takaro:

  1. In Takaro, open the Settings page (at the bottom of the left menu).
  2. Turn on Developer Mode.
  3. Click Module Builder on the left.
  4. Click Module Actions.
  5. Click Import Module and pick the .json file you downloaded.
  6. After it imports, install it on your server: on the left, click Game Servers → your server → Modules.
For Discord: once the Discord Integration - Generic module is installed, set your Discord channel in the module's settings. See Takaro's documentation for connecting Discord to Takaro and inviting the bot.

Chat Integration — In-Game Chat & Discord

Want in-game chat showing in Takaro or Discord? You need this. It forwards chat to and from Takaro (and Discord, via the Discord Integration module from Step 6) by installing a small mod (UE4SS) on the game server.

Use the Palworld-specific UE4SS. Since Palworld patch 0.4.1.5 the normal UE4SS crashes the server. Download UE4SS-Palworld.zip from Okaetsu's experimental-palworld release. If you had another UE4SS installed, delete the old dwmapi.dll and ue4ss folder first.

1. Install UE4SS

  1. Download UE4SS-Palworld.zip from the link above and unzip it.
  2. Copy dwmapi.dll and the ue4ss folder into PalServer\Pal\Binaries\Win64\.
  3. If Windows blocked the files: right-click each → Properties → Unblock → Apply.

2. Restart the Palworld Server

The bridge installs the chat mod for you when you run PalworldBridge.exe (with UE4SS in place). Then stop and start your Palworld server — UE4SS and the mod load on boot, and chat starts flowing.

Available Commands

Use these in the Takaro web console (not in-game):

  • help — List all commands
  • players — Show online players
  • serverinfo — Server details
  • metrics — Server metrics
  • settings — Server settings
  • announce <message> — Send an announcement
  • save — Save the world
  • shutdown [seconds] [message] — Shutdown with countdown
  • stop — Stop immediately
  • kick <player_name> — Kick a player
  • ban <player_name> — Ban a player
  • unban <steam_id> — Unban a player
  • teleportplayer <source> <target> — Teleport a player to another player
  • teleportplayer <source> <x> <y> <z> — Teleport a player to coordinates
  • location <player_name_or_gameid> — Get live player coordinates
