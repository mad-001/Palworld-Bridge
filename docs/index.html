Palworld-Takaro Bridge

Connect your Palworld dedicated server to Takaro for player management, server control, teleports, and in-game chat.

Download the Bridge

What You Get

  • Server control from Takaro — kick, ban, announce, save, and shut down from the Takaro web console.
  • Player tracking — who's online, plus join/leave events.
  • Teleports — player-to-player and coordinate teleports.
  • Location lookup — live X/Y/Z coordinates for any player.
  • In-game chat — forward chat between your game, Takaro, and Discord.

Before You Start

  • A Palworld dedicated server you control (so you can edit its settings and restart it).
  • The Windows machine your server runs on (the bridge runs on the same machine).
  • A Takaro account — free to start at takaro.io.

Step 1 — Get Your Takaro Tokens

  1. Go to takaro.io and choose the Free tier to start.
  2. Check your email and finish creating your account, then log in.
  3. Click Game servers.
  4. Click Game Server Actions in the top right.
  5. Click Create a New Game Server.
  6. Choose Generic as the server type.
  7. Takaro shows a Registration Token. Copy it — you'll paste it in Step 5.
  8. Click Cancel.

Step 2 — Stop Your Palworld Server

Stop the server before you set things up.

Step 3 — Enable the Palworld REST API

In PalWorldSettings.ini (at [Server folder]\Pal\Saved\Config\WindowsServer\PalWorldSettings.ini), set:

RESTAPIEnabled=True
RESTAPIPort=8212
AdminPassword=YourSecurePassword

Step 4 — Install UE4SS (for in-game chat)

Use the Palworld-specific UE4SS. Since Palworld patch 0.4.1.5 the normal UE4SS crashes the server. Download UE4SS-Palworld.zip from Okaetsu's experimental-palworld release. If you had another UE4SS installed, delete the old dwmapi.dll and ue4ss folder first.
  1. Download UE4SS-Palworld.zip and unzip it.
  2. Copy dwmapi.dll and the ue4ss folder into [Server folder]\Pal\Binaries\Win64\.
  3. If Windows blocked the files: right-click each → Properties → Unblock → Apply.

Step 5 — Install the Bridge

  1. Download PalworldBridge.exe and put it in your server folder — the one that contains Pal (for example C:\gameservers\palworld).
  2. Right-click it → Run as administrator. It fills in the Palworld settings, creates TakaroConfig.txt, and installs the chat mod. Close the window when it says it needs your token. (Windows may warn "Windows protected your PC" → More info → Run anyway.)
  3. Open TakaroConfig.txt (next to the exe) and set these two lines, then save: 
    SERVER_NAME=any name you want for your server
REGISTRATION_TOKEN=paste the token from Step 1

Step 6 — Add the Takaro Modules

Modules add features to your Takaro server. Download these two (right-click → Save Link As, or open and use GitHub's Download raw file button):

  • Palworld - Commands — adds the player commands !sethome, !home, and !visit.
  • Discord Integration - Generic — connects your game to Discord: player join / leave / death messages, an online-offline status message, and two-way chat.

Import each one into Takaro:

  1. In Takaro, open the Settings page (bottom of the left menu).
  2. Turn on Developer Mode.
  3. Click Module Builder on the left.
  4. Click Module Actions → Import Module and pick the .json file.
  5. After it imports, install it: on the left, click Game Servers → your server → Modules.
For Discord: once the Discord Integration - Generic module is installed, set your Discord channel in its settings. See Takaro's docs for connecting Discord and inviting the bot.

Step 7 — Start Everything

Start your Palworld server, then run PalworldBridge.exe. The bridge connects to Takaro and your server appears in your Takaro dashboard. Leave the bridge window open while you want it running.

Available Commands

Use these in the Takaro web console (not in-game):

  • help — List all commands
  • players — Show online players
  • serverinfo — Server details
  • metrics — Server metrics
  • settings — Server settings
  • announce <message> — Send an announcement
  • save — Save the world
  • shutdown [seconds] [message] — Shutdown with countdown
  • stop — Stop immediately
  • kick <player_name> — Kick a player
  • ban <player_name> — Ban a player
  • unban <steam_id> — Unban a player
  • teleportplayer <source> <target> — Teleport a player to another player
  • teleportplayer <source> <x> <y> <z> — Teleport a player to coordinates
  • location <player_name_or_gameid> — Get live player coordinates
